## Heading level two

Second-level headings open the major divisions of a Post. The paragraph that follows sits
tighter against its heading than it does against a preceding paragraph, which is what the
flow rhythm in `prose.css` is for.

### Heading level three

Third-level headings subdivide a section. They keep the same weight and color as their
parents and separate on size alone.

#### Heading level four

The smallest heading in the scale, one step above body copy.

  - A nested item
  - A second nested item

An ordered list:

1. Establish the constraint
2. Build the smallest thing that satisfies it
3. Layer the rest on top

## Code

Fenced code runs through Expressive Code, which owns highlighting, the frame, and the
title bar:

```ts title="src/lib/utils/date.ts"
export function parseContentDate(date: Date | string | undefined) {
	if (!date) return;
	if (date instanceof Date) return date;

	return new Date(date);
}
```

A block with no language and no title falls back to the plain frame:
